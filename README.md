# Pokémon Cards Telegram Bot

Бот для группы по обмену и продаже Pokémon-карт: фиксированные объявления и аукционы.

## Возможности

**Продажа (`/sell`)**

- Мастер: добавление нескольких товаров по порядку, цена, описание; фото добавляются отдельной кнопкой к посту
- Один пост в группе со списком товаров и отдельной кнопкой покупки для каждого товара
- Нажатие на кнопку товара сразу резервирует его
- **Продано** / **Снять резерв** / **Отменить** — по товарам в `/my`

**Аукцион (`/auction`)**

- Стартовая цена, минимальный шаг ставки, дата окончания
- Кнопка **Сделать начальную ставку** до первой ставки, затем **Сделать шаг ставки**
- В посте: текущая ставка, лидер (потенциальный покупатель), время окончания
- По окончании (автоматически или кнопка «Завершить аукцион» в `/my`) — уведомления в ЛС

- `/groupid` — ID чата для `.env`

## Установка

```bash
cd pokemon-cards-bot
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен от BotFather |
| `GROUP_CHAT_ID` | ID группы |
| `ADMIN_IDS` | User id через запятую |
| `SELLER_IDS` | Белый список продавцов для `/sell`, `/auction`, `/my`; если пусто — доступны всем |
| `SALE_TOPIC_ID` | ID топика для объявлений о продаже; если пусто — публикация идёт в общий чат |
| `AUCTION_TOPIC_ID` | ID топика для аукционов; если пусто — публикация идёт в общий чат |
| `AUCTION_TIMEZONE` | Часовой пояс дат аукциона (по умолчанию `Europe/Chisinau`) |

## Настройка группы

1. Добавьте бота в группу с правами на отправку и **редактирование** сообщений.
2. BotFather: `/setprivacy` → **Disable**.
3. `/groupid` в группе → `GROUP_CHAT_ID`.

## Запуск

```bash
.venv\Scripts\python.exe -m bot
```

## Команды

| Команда | Где | Действие |
|---------|-----|----------|
| `/start` | ЛС | Справка |
| `/id` или `/myid` | ЛС/группа | Показать Telegram ID пользователя для whitelist |
| `/sell` | ЛС | Объявление с фикс. ценой |
| `/auction` | ЛС | Создать аукцион |
| `/my` | ЛС | Мои лоты |
| `/cancel` | ЛС | Отменить мастер |
| `/allow <id>` | ЛС | Добавить пользователя в whitelist (админ) |
| `/deny <id>` | ЛС | Удалить пользователя из whitelist (админ) |
| `/allowed` или `/list_allowed` | ЛС | Показать динамический whitelist (админ) |
| `/groupid` | Группа | ID чата |
| `/topicid` | Топик группы | ID текущего топика |

Whitelist личного меню хранится в базе `data/bot.db` и обновляется без перезапуска через команды `/allow` и `/deny`. Админы из `ADMIN_IDS` всегда имеют доступ.

Чтобы публиковать продажи и аукционы в разные топики, напишите `/topicid` внутри нужного топика и вставьте полученный id в `SALE_TOPIC_ID` или `AUCTION_TOPIC_ID`.

## Аукцион: дата окончания

Форматы (в часовом поясе `AUCTION_TIMEZONE`):

- `15.06.2026 20:00`
- `15.06.2026` — до 23:59 этого дня

## Ставки

- Первая ставка: не ниже стартовой цены
- Каждая следующая: не ниже текущей + минимальный шаг
- Перебитый участник получает уведомление в ЛС

База данных: `data/bot.db` (миграции колонок при старте).
